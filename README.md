# React Authentication UI

A simple authentication UI built using React.

## Features

- Login Page
- Registration Page
- Form Validation
- Email Validation (Regex)
- Password Validation
- Gender Selection
- Country Dropdown
- Skills Selection
- Toast Notifications
- React Router Navigation

## Technologies Used

- React.js
- Vite
- Tailwind CSS
- React Router DOM
- React Hot Toast

## Concepts Covered

- useState
- Controlled Components
- Form Validation
- Event Handling
- React Router
  - BrowserRouter
  - Routes
  - Route
  - Link
  - useNavigate
